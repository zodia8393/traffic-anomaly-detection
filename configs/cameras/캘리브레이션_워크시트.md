# 카메라 캘리브레이션 워크시트 (5대)

> 속도/TTC를 절대값(km/h)으로 산출하려면 카메라별 호모그래피가 필요하다.
> 정확한 호모그래피는 **영상 속 도로 4점의 픽셀좌표 + 실세계 좌표(m)** 측정이 필수다.
> (자동 추정은 부정확 → 절대속도를 틀린 채 신뢰하게 만들어 위험하므로 미생성)

## 측정 절차

1. `_calibration_aids/<카메라>_grid.png` 열기 (1280×720, 50px 격자)
2. 도로 노면 위 **사다리꼴 4점** 선택 (차로 경계선·정지선 등 평면상 점):
   - 가까운 쪽(하단) 좌·우 2점, 먼 쪽(상단) 좌·우 2점
   - 각 점의 **픽셀좌표(x,y)** 를 격자로 읽기
3. 4점의 **실세계 좌표(m)** 부여:
   - 가로(X): 차로폭 **3.5m** 기준 (고속도로 표준). N개 차로면 0 ~ 3.5N m
   - 세로(Y): 차로 점선(흰색 파선) 주기 활용 — 고속도로 표준 **칠 8m + 공백 12m = 20m/주기**
4. 도구 실행:
```bash
cd src/layer1_vision
python3 make_calibration.py --camera <카메라> \
  --img-pts "x1,y1 x2,y2 x3,y3 x4,y4" \
  --world-pts "0,0 7,0 7,40 0,40"     # 예: 2차로폭(7m) × 40m
# → configs/cameras/<카메라>.json (재투영 RMSE 1m 이내 권장)
```

## 검증

- 생성된 JSON의 `reproj_rmse_m < 1.0` 확인
- `SpeedEstimator(configs/cameras/<카메라>.json).is_calibrated == True`
- 알려진 속도 차량(예: 제한속도 표지)으로 산출 속도 교차검증 권장
