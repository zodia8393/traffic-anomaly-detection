## 반영해야 할 실측 데이터

### 영상 수집 (모드 B: 연속 녹화)
- **확정 방식**: Python m3u8 세그먼트 직접 다운로드 (record_hls_multi.py)
- **원리**: HLS master playlist → ffprobe로 media playlist URL 추출 → m3u8 파싱 → .ts 세그먼트 HTTP GET → 단일 파일 append
- **세션 만료**: ~5분마다 403 → 자동 재수립 (nimblesessionid 갱신)
- **출력 포맷**: MPEG-TS (.ts), H.264, 720×480
- **비교 (ffmpeg 방식 탈락 이유)**: 세션 만료 시 프로세스 crash → 24시간 기준 카메라당 ~280개 프래그먼트 → 후처리 merge 필요. HLS 직접 방식은 단일 파일 연속 녹화.
