## 구현 지침

### python-pptx 구현 순서
1. 원본 PPT를 복사 (`shutil.copy2`)
2. 레이아웃 `"02_과업 추진체계 및 일정의 적정성"` 사용
3. 슬라이드 13 뒤에 새 슬라이드 6장 삽입
4. 각 슬라이드에 헤더 요소 배치 (플레이스홀더 + TextBox)
5. 콘텐츠 도형 배치

### 헤더 구현 방법
레이아웃 플레이스홀더(idx=0 제목, idx=10 부제목)는 자동 상속됨.
추가로 TextBox 3(장번호)와 텍스트 개체 틀 19(설명)은 직접 추가.
그룹 492(파란 헤더바)는 슬라이드 마스터/레이아웃에 포함되어 자동 상속됨.
