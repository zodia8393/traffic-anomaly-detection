## POI 설정 시 변화 (경부선 — 정확한 도로 ROI)
- **ROI 밖 검출 473건 필터링** → 도로 밖(방음벽·하늘·원거리 객체) 오탐 제거
- **고유트랙 320→297 (-7%)** — 허위/단발 트랙 감소
- **박스 지터 10.27→8.76 (-15%)** — 바운딩박스 깜빡임/흔들림 감소
- **불안정 클래스 트랙 42→28 (-33%)** — ID/클래스 플리커 감소
- **처리 속도 동일(~56fps)** — ROI는 검출 후 필터라 YOLO 부하 불변

## ⚠ POI ROI 정확도의 중요성 (남해선 — 일반 ROI)
- 일반 ROI(하단 60%)가 남해선 실제 도로와 불일치 → **2060건 과도 필터**(절반 이상)
- **박스 지터 오히려 증가(7.47→10.14)** — 도로 일부 잘림 + 경계 효과
- → **카메라별 정확한 ROI 없으면 POI가 역효과**

## 핵심 결론
| 항목 | POI off (기준) | POI on (정확ROI) |

| 오탐(도로밖) | 포함 | **필터됨** |
| 트래킹 안정성 | 기준 | **지터 -15%·플리커 -33%** |
| 처리 속도 | 기준 | 동일(후필터) |
| 설정 부담 | 없음 | **카메라별 ROI 필요** |
| 잘못된 ROI 위험 | 없음 | **과필터·역효과** |

## 권고
- **기본 미설정(전체프레임)이 안전한 baseline** — 설정 부담 0, 역효과 0
- **POI 권장 조건**: 카메라별 정확한 도로 ROI를 정의할 수 있을 때 → 오탐 제거 + 트래킹 안정화(-15~33%) 이득
- **금지**: 일반/대충 ROI는 과필터·역효과(남해선 사례) → 정확한 ROI 없으면 켜지 말 것
- **처리속도 목적이면 무효** — ROI는 후필터라 속도 이득 없음(속도는 사전 크롭 필요)
- 보행자 트리거(T8): 정상 고속도로 footage엔 보행자 0 → 미발화(정상). 실보행자 시 발화 검증은 별도 필요

## 적용 (강화·안정화 코드)
- 차량감지강화: imgsz 640→736, 차량+보행자(0,2,3,5,7), agnostic NMS, FP32(INT8 금지)
- 트래킹 안정화: bbox EMA 평활(α0.6), ID 유지
- 보행자 트리거: trigger_detector T8
- POI 토글: analyze_detection --roi (미지정 시 전체프레임)
