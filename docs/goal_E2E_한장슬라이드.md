# Goal: ITS API → 입력 → 출력 → AI영상 E2E 한 장 슬라이드 추가

## 목적

「교통센터 생성형 AI 상황관제 12-13장」 PPT에 **한 장짜리 슬라이드**를 추가한다.
이 한 장에 **"어디에서(ITS) → 어떻게 입력(요청변수) → 어떤 출력값(응답/엑셀) → 그게 어떤 영상이 되는지(VLM PoC)"** 전체 흐름이 좌→우로 한눈에 보이도록 한다.

## 입력 자원 (모두 확인됨)

| # | 자원 | 경로 | 용도 |
|---|------|------|------|
| 1 | ITS Open API 페이지 | `https://www.its.go.kr/opendata/opendataList?service=cctv` | **전체 캡쳐** → "어디에서" |
| 2 | 샘플 데이터 엑셀 | `/workspace/prj_cctv/사고분석_설계/output/ITS_CCTV_샘플데이터_20260601.xlsx` | 출력값 표 (167건) |
| 3 | VLM PoC 영상 | `/workspace/prj_cctv/사고분석_설계/output/demo_vlm_poc.mp4` | "어떤 영상" → 대표프레임/임베드 |
| 4 | 대상 PPTX | `/workspace/_inbox/교통센터_생성형AI_상황관제_12-13장 (1).pptx` | 슬라이드 추가 대상 |

## 작업 순서 (단계 → 검증)

### 1단계: ITS 페이지 전체 캡쳐
- Playwright로 `https://www.its.go.kr/opendata/opendataList?service=cctv` 접속
- **전체 페이지 풀스크린샷** (full_page=True), 1280px+ 폭
- 저장: `docs/assets/its_opendata_cctv_page.png`
- **검증**: 파일 존재 + "요청변수/출력변수" 표가 캡쳐에 포함됐는지 육안 확인

### 2단계: PoC 영상 포스터 프레임 추출 (영상 임베드용 썸네일)
- `demo_vlm_poc.mp4`에서 패널에 항목이 여러 개 누적된 시점(예: 프레임 8500, ~4.7분) 1장 추출
- 좌측 CCTV+검출박스 + 우측 "AI CCTV 상황 정보" 패널이 함께 보이는 합성 프레임
- 저장: `docs/assets/vlm_poc_poster.png`
- **용도**: ④ 영역 영상 플레이스홀더의 **포스터(표지) 이미지** — 재생 전 표시되는 썸네일
- **검증**: 좌 CCTV / 우 AI패널(최신 상단) 둘 다 선명한지 확인

### 3단계: 대상 PPTX 디자인 분석
- python-pptx로 기존 PPTX 열기
- 슬라이드 크기(EMU), 폰트(KoPub돋움체/맑은고딕 등), 색상 팔레트(#00488C, #FFC000, #FF0000 등) 추출
- 기존 슬라이드 1장 레이아웃 참조 (제목 위치/크기, 본문 스타일)
- **검증**: 추가 슬라이드가 기존과 같은 크기·폰트·색상 톤을 따르는지

### 4단계: 한 장 슬라이드 구성

**제목**: `ITS Open API 기반 CCTV 영상 → AI 상황정보 추출 (End-to-End)`

**본문: 좌→우 4단계 플로우 (화살표 연결)**

```
┌──────────────┐   ┌──────────────┐   ┌──────────────┐   ┌──────────────┐
│ ① 데이터 소스 │ → │ ② 입력        │ → │ ③ 출력값      │ → │ ④ AI 분석영상 │
│              │   │ (요청변수)    │   │ (응답)        │   │ (VLM PoC)    │
├──────────────┤   ├──────────────┤   ├──────────────┤   ├──────────────┤
│ ITS 국가교통  │   │ apiKey=발급키 │   │ datacount=167 │   │ [PoC 캡쳐]    │
│ 정보센터      │   │ type=ex       │   │ cctvname      │   │ 좌:CCTV+박스  │
│ Open API     │   │ cctvType=1    │   │ cctvurl       │   │ 우:AI 상황정보 │
│ [페이지 캡쳐] │   │ minX~maxY     │   │ coordx/coordy │   │ 기상/차로/    │
│              │   │ getType=json  │   │ [엑셀 167건]  │   │ 소통/이상징후 │
└──────────────┘   └──────────────┘   └──────────────┘   └──────────────┘
   "어디에서"        "어떻게 입력"        "어떤 출력"          "어떤 영상"
```

- ① 영역: ITS 페이지 캡쳐 이미지(1단계 산출) 축소 삽입
- ② 영역: 요청변수 8개를 간결한 표/박스로 (apiKey·type·cctvType·minX~maxY·getType)
- ③ 영역: 응답 핵심 필드 + datacount=167 + 엑셀 아이콘/썸네일
- ④ 영역: **PoC 영상 재생 플레이스홀더** — `demo_vlm_poc.mp4`를 슬라이드에 임베드,
  포스터 프레임(2단계 산출)을 표지로, ▶ 재생 아이콘 오버레이. 캡션 "CPU VLM 실시간 상황정보 추출 (클릭 재생)"
- 단계 사이 **화살표(→)** 4개로 흐름 강조
- 하단 한 줄 요약: `좌표 범위 입력 → CCTV 목록·스트림 URL 수신 → 영상 수집 → AI가 기상·소통·이상징후 자동 추출`

#### ④ 영상 임베드 사양 (핵심 변경)
- python-pptx `slide.shapes.add_movie(mp4, x, y, w, h, poster_frame_image=poster_png, mime_type="video/mp4")`
- **영상이 PPTX 안에 내장**되어 발표 중 슬라이드에서 직접 ▶ 클릭 재생 (외부 파일 불필요)
- 포스터 이미지 = 2단계 `vlm_poc_poster.png` (재생 전 썸네일)
- 용량: mp4 55MB가 PPTX에 포함 → 최종 PPTX ~57MB (수용)
- **호환성 주의**: PowerPoint(데스크톱)에서 정상 재생. 임베드 코덱은 H.264/mp4 (이미 변환됨)
- **검증**: 저장 후 PPTX 내 `ppt/media/`에 mp4 포함 확인 + 슬라이드에 movie shape 존재

### 5단계: PPTX 저장 (원본 보존)
- 기존 슬라이드 **전부 유지** + 신규 1장을 **맨 끝에 추가**
- 원본 덮어쓰기 금지 → 새 파일로 저장:
  `/workspace/_inbox/교통센터_생성형AI_상황관제_12-13장_E2E추가_20260601.pptx`
- **검증**: 슬라이드 수 = 원본+1, 신규 슬라이드에 4개 이미지/표 + 화살표 + 제목 존재
