# 사고감지 성능 개선 보고서

> 2026-06-02 | "사고감지 성능이 너무 낮다" → 진단·개선

## 진단: 왜 낮았나
| 구성요소 | 상태 | 원인 |
|---------|------|------|
| **STGAE (Level4)** | AUROC **0.49 (랜덤)** | 비지도 reconstruction이 **라벨을 버림** — autoencoder가 비정상 궤적도 정상처럼 복원 |
| Level2/3 (IForest·LSTM) | 미통합 | ml_scores 항상 None |
| 트리거 7종 | 동작 | 규칙기반, recall 미측정 |
| 데이터 | **정상** (636GB) | train 1973(정상)/test 2961(비정상2467+정상494), 비정상 7종 |

핵심: **데이터에 라벨이 있는데 비지도 STGAE라 안 씀.**

## 개선: 지도 궤적 감지기
궤적 운동학 특징(속도·가속도·방향변화·정지·횡방향·차량간) **28종** → 지도분류기.

| 모델 | AUROC |
|------|------|
| STGAE (기존, 비지도) | 0.490 |
| **RandomForest (신규, 지도)** | **0.916** (+0.426) |
| GradientBoosting | 0.898 |
| XGBoost | 0.892 |

- 운영점(임계 0.80): **recall 0.74 · 오탐(FPR) 0.08**
- 유형별 recall: an2=0.95 an6=0.93 an4=0.84 an5=0.80 (강) / an1=0.48 an3=0.54 an7=0.61 (약)

## 비정상 7종 = 차선변경 위반 (분석)
an1 방향지시등불이행 · an2 실선차선변경 · an3 동시차로변경 · an4 차선물기 ·
an5 2개차로연속변경 · an6 정체구간차선변경 · an7 안전거리미확보

**천장 분석**:
- **an1**(방향지시등) — 궤적 x,y에 깜빡이 정보 없음 → 운동학으로 **원천 감지 불가**(0.48 한계)
- an3/an7 — 차량간 관계 특징 추가로 소폭 개선, 미묘한 다차량 패턴은 어려움
- → **0.916은 궤적 모달리티 천장**. 추가 개선은 영상기반(깜빡이 검출) 필요

## 후속 #1: 방향지시등(깜빡이) 영상검출 — an1 보완 시도
- **단독 검출 성공**: CCTV 차량 크롭 amber 점멸 → an1(불이행)=점멸 0.0 vs 정상이행=1.9 (깨끗한 분리, 검출 가능 입증)
- **그러나 클립단위 an1 개선 실패**: an1(차선변경+무신호)과 정상직진(무신호) 둘 다 blink≈0 → 이진 분류에서 구분 불가. blink 중요도 0.02(26/29위)
- **천장**: an1은 per-vehicle(차선변경∧무신호 상호작용) 모델 필요. 클립 집계특징의 한계
- **부수 이득**: 균형 데이터(val_extracted 1260/1260)로 recall 0.737→0.757, an3 0.54→0.60, an6 0.93→0.97
- 산출물: `turn_signal_detector.py`(검증된 모듈), `build_dataset_v2.py`
