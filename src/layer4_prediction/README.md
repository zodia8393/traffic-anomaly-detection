# Layer 4: 사고 예측

축적된 데이터로 **"앞으로 30분 내 사고가 날 확률"**을 예측합니다.
AI 판단(Layer 3)이 만든 위험도 + 교통류 통계를 학습하여 위험 구간을 사전에 경고합니다.

## 하는 일

```
축적 데이터 (Layer 2)
  │
  ├── 교통량·속도·화물차 비율  (5분 단위)
  ├── AI 위험도 점수           (트리거마다)
  └── 과거 사고 이력           (누적)
  │
  ▼
피처 생성 (19개 지표)
  │
  ▼
XGBoost 모델 예측
  │
  ▼
┌──────────────────────────────┐
│  사고 확률: 0.73 (high)       │
│  주요 원인: 속도분산↑, 화물↑  │
│  위험 순위: 전체 IC 중 3위    │
└──────────────────────────────┘
  │
  ▼
위험 구간 히트맵 + 경고 알림
```

## 파일 설명

| 파일 | 역할 |
|------|------|
| `feature_engineer.py` | DB에서 19개 예측 지표를 추출·가공 |
| `accident_predictor.py` | XGBoost 모델 학습·예측·평가 |
| `risk_scorer.py` | 전체 IC 위험도 순위 + 히트맵 데이터 생성 |

## 예측에 사용하는 19개 지표

| 분류 | 지표 | 설명 |
|------|------|------|
| 교통류 (6개) | volume | 5분간 통과 차량 수 |
| | avg_speed | 평균 속도 |
| | speed_std | 속도 편차 (클수록 위험) |
| | truck_ratio | 화물차 비율 |
| | speed_change_rate | 속도 변화율 |
| | volume_change_rate | 교통량 변화율 |
| AI 판단 (6개) | risk_score | AI가 평가한 위험도 |
| | risk_score_ma3 | 위험도 3구간 이동평균 |
| | anomaly_count | 이상 감지 횟수 |
| | trigger_ttc_count | 충돌위험 트리거 횟수 |
| | trigger_decel_count | 급감속 트리거 횟수 |
| | trigger_stop_count | 정차 트리거 횟수 |
| 시간 (4개) | hour | 시간대 (0~23) |
| | day_of_week | 요일 (0=월~6=일) |
| | is_weekend | 주말 여부 |
| | is_rush_hour | 출퇴근 시간대 여부 |
| 공간 (3개) | ic_type | IC/JC/터널/본선 구분 |
| | hist_accident_rate | 과거 사고 빈도 |
| | hist_avg_volume | 과거 평균 교통량 |

## 위험도 기준

| 확률 | 등급 | 의미 |
|------|------|------|
| 0.7 이상 | critical | 즉시 주의 필요 |
| 0.5~0.7 | high | 주의 관찰 |
| 0.3~0.5 | medium | 모니터링 |
| 0.3 미만 | low | 정상 |

## 목표 성능

- **AUC 0.7 이상** (Phase 4 게이트 조건)
- 학습 데이터: Phase 2~3에서 축적된 AI 판단 + 교통류 시계열
