# Layer 2: 데이터 저장

모든 분석 결과를 **DuckDB 데이터베이스**에 구조화 저장합니다.
과거 데이터 검색, 교통량 집계, 유사 사고 사례 조회에 사용됩니다.

## 하는 일

```
영상 분석 결과 (Layer 1)  ──┐
                             ├──→  DuckDB 저장  ──→  검색·집계·분석
AI 판단 결과 (Layer 3)    ──┘
```

## 데이터베이스 테이블 5개

| 테이블 | 저장 내용 | 주요 용도 |
|--------|----------|----------|
| `tracks` | 차량별 궤적·차종·속도 | 교통량 집계, 차종 통계 |
| `mllm_responses` | AI 판단 원문 (JSON) | 판단 이력 추적, 품질 검증 |
| `accidents` | 사고 이벤트 (93컬럼 서식) | 사고 기록, 보고서 기반 |
| `report_archive` | 과거 사고 보고서 | 유사 사례 검색 |
| `traffic_agg` | 5분 단위 교통류 집계 | 사고 예측 피처 |

## 파일 설명

| 파일 | 역할 |
|------|------|
| `db_schema.py` | 데이터베이스 테이블 생성 (최초 1회) |
| `metadata_writer.py` | 분석 결과를 DB에 저장 (INSERT/UPDATE) |
| `traffic_aggregator.py` | 5분 단위로 교통량·속도·화물차 비율 집계 |
| `report_indexer.py` | 과거 사고 보고서를 DB에 적재하고 유사 사례 검색 |

## 유사 사례 검색 방식

```
새 사고 발생
  │
  ▼
사고 정보를 텍스트로 변환
  ("경부 상행 추돌 화물차+승용차")
  │
  ▼
임베딩 생성 (sentence-transformers 또는 TF-IDF)
  │
  ▼
과거 보고서와 코사인 유사도 비교
  │
  ▼
가장 비슷한 사고 3건 반환
  → AI 판단 시 참고 자료로 활용
```

## 데이터 흐름

- **입력**: Layer 1(영상 분석)의 트랙 데이터, Layer 3(AI)의 판단 결과
- **출력**: Layer 3에 유사 사례 제공, Layer 4(사고 예측)에 집계 데이터 제공
