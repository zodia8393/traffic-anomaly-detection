# Layer 1: 영상 분석

CCTV 영상을 프레임 단위로 처리하여 **차량 탐지 → 추적 → 속도 계산 → 이상 감지**를 수행합니다.
이 레이어의 출력이 Layer 3(AI 판단)의 입력이 됩니다.

## 하는 일

```
CCTV 영상
  │
  ▼
차량 탐지 (YOLO)          ← 기존 pipeline/detector.py 재사용
  │
  ▼
차량 추적 (ByteTrack)     ← 기존 pipeline/tracker.py 재사용
  │
  ▼
1차 차종 분류 (13종)      ← 기존 pipeline/ensemble_classifier.py 재사용
  │
  ▼
속도·충돌위험 계산        ← speed_estimator.py, ttc_calculator.py
  │
  ▼
이상 상황 감지            ← trigger_detector.py (7종 트리거)
  │
  ▼
핵심 장면 선정            ← keyframe_selector.py
  │
  ▼
AI 판단 호출 (Layer 3으로 전달)
```

## 파일 설명

| 파일 | 역할 | 입력 | 출력 |
|------|------|------|------|
| `speed_estimator.py` | 픽셀 궤적 → 실제 속도(km/h) 변환 | 차량 좌표, 타임스탬프 | 속도 리스트 |
| `ttc_calculator.py` | 두 차량 간 충돌 예상 시간 계산 | 차량 쌍의 궤적 | TTC(초) |
| `trigger_detector.py` | 이상 상황 7종 감지 | 속도, TTC, 궤적 | 트리거 이벤트 |
| `keyframe_selector.py` | AI에 보낼 핵심 장면 선정 | 프레임 버퍼, 트리거 시점 | 프레임 번호 리스트 |
| `vision_pipeline.py` | 위 모듈을 하나로 조합하여 실행 | 영상 파일 | AI 입력 패키지 |

## 이상 감지 트리거 7종

| 코드 | 조건 | 예시 |
|------|------|------|
| T1 | 충돌 예상 시간 3초 미만 | 앞차와 급접근 |
| T2 | 급감속 (-3m/s² 이하) | 급브레이크 |
| T3 | 비정차 구간에서 정차 | 본선에 차량 멈춤 |
| T4 | 역주행 감지 | 반대 방향 주행 |
| T5 | 3대 이상 동시 급감속 | 연쇄 급정거 |
| T6 | 속도 분산 급증 | 차량 간 속도 차이 급증 |
| T7 | 5분 주기 자동 촬영 | 정상 상황 기록용 |

## 핵심 장면 선정 기준

1. 차량이 크고 선명한 프레임 (bbox 면적 × 검출 신뢰도)
2. 화면 중앙에 가까운 프레임
3. 트리거 시점 프레임은 반드시 포함
4. 연속 프레임 제외 (최소 1초 간격)
5. 최대 5장 선정
