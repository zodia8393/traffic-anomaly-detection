# Layer 3: AI 판단 (핵심)

**시스템의 핵심 두뇌.** 멀티모달 AI(MLLM)가 CCTV 장면을 보고 사고 여부, 차종, 원인을 판단합니다.
매 프레임 호출이 아니라, Layer 1에서 이상 징후를 감지했을 때만 호출됩니다.

## 하는 일

```
이상 감지 (Layer 1에서 트리거)
  │
  ▼
핵심 장면 + 차량 데이터 수신
  │
  ▼
┌─────────────────────────────────┐
│  Task 1. 장면 파악               │  "지금 도로 상황이 어떤가?"
│            │                     │
│            ▼                     │
│  Task 2. 사고 판정               │  "사고가 발생했는가?"
│         ╱     ╲                  │
│       NO      YES                │
│       │        │                 │
│    기록만   Task 3. 차종 보정     │  "이 차량은 정확히 몇 종?"
│              │                   │
│              ▼                   │
│         Task 4. 원인 분석        │  "왜 사고가 났는가?"
│          + 보고서 자동 작성      │  "93컬럼 보고서 채워라"
└─────────────────────────────────┘
  │
  ▼
구조화 결과 (JSON) → Layer 2에 저장, 즉시 알림
```

## 파일 설명

| 파일 | 역할 |
|------|------|
| `mllm_client.py` | AI 모델과 통신하는 인터페이스 (CPU↔GPU 전환 시 이것만 변경) |
| `mllm_server.py` | 로컬 AI 서버 시작/중지/상태 확인 |
| `prompts.py` | AI에게 보내는 질문 템플릿 4종 |
| `scene_analyzer.py` | Task 1: 장면 파악 ("도로 상황 설명해라") |
| `accident_detector.py` | Task 2: 사고 판정 ("사고인가 아닌가?") |
| `class_corrector.py` | Task 3: 차종 보정 ("화물차를 13종 중 정확히 어디?") |
| `report_generator.py` | Task 4: 원인 분석 + 93컬럼 보고서 자동 작성 |

## AI 모델

| 단계 | 모델 | 환경 | 속도 |
|------|------|------|------|
| 1단계 (POC) | Qwen2.5-VL-7B (경량) | CPU 로컬 | ~30초/요청 |
| 2단계 (목표) | Qwen2.5-VL-72B (고성능) | GPU 서버 | ~2초/요청 |

전환 시 `mllm_client.py`의 접속 주소만 변경하면 됩니다.

## CPU 부하

| 상황 | AI 호출 빈도 | CPU 사용 |
|------|-------------|---------|
| 평시 | 시간당 ~12회 | 10~15% |
| 혼잡 | 시간당 ~17회 | ~15% |
| 사고 | 집중 ~10회 | 집중 처리 |

**매 프레임 호출이 아님** → CPU에서도 충분히 운용 가능

## 차종 보정이 중요한 이유

사고 보고서에서 "화물차"는 전체의 58%를 차지하지만,
실제로는 T3(포터)부터 T12(초대형 트레일러)까지 **10종**에 해당합니다.

```
보고서: "화물차"  →  AI가 CCTV 장면을 보고 판단:
                     ├── T3  소형화물 (포터, 봉고)
                     ├── T4  중형화물 (마이티)
                     ├── T5  대형화물 (3축 카고)
                     ├── T6  대형특수 (4축 레미콘)
                     ├── T7  대형특수 (5축)
                     ├── T8  세미트레일러 (4축)
                     ├── T9  풀트레일러 (4축)
                     ├── T10 세미트레일러 (5축, 컨테이너)
                     ├── T11 풀트레일러 (5축)
                     └── T12 세미트레일러 (6축, 초대형)
```
